# OwlCanvas 🎨

**A free digital painting application by Owl's Eye Abstract Studio.**

OwlCanvas is an open-source project to develop a professional digital drawing and painting application for Android phones.

Our goal is to make powerful creative tools accessible to everyone without subscriptions or paid features.

## ✨ Planned Features

- 🎨 Digital painting and drawing
- 🖌️ Multiple brush types
- 🌈 Colour wheel and custom palettes
- 🗂️ Multilayer editing
- ↩️ Undo and redo
- ✏️ Eraser and selection tools
- 💾 Local project saving
- 🖼️ High-resolution image export
- 📱 Android-first interface
- 🔌 Offline-first operation

## 🚧 Project Status

Early development and planning.

Features will be implemented and tested progressively.

## 💰 Project Philosophy

- Free core features.
- No mandatory subscriptions.
- No advertisements.
- No mandatory account.
- Local storage for artwork.
- Open-source development.

## 🛠️ Development

The initial goal is to establish a working drawing engine, followed by layers, brush improvements, project storage, and advanced illustration tools.
